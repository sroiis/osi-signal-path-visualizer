# OSI Signal Path Visualizer

An interactive simulation project demonstrating data flow across OSI layers including routing, framing, transmission, and KPI analysis.

## Features
- OSI Layer Simulation
- Packet Visualization
- KPI Monitoring
- Routing Demonstration
- Interactive Controls
-
